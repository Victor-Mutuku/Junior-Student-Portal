# Junior Student Portal

A CRUD web application built with **C# and ASP.NET MVC**, using **Dependency Injection** to manage student records.

---

## Project Overview

This project implements a student management system where users can **create, view, edit, and delete** student records. It follows the **MVC (Model-View-Controller)** architectural pattern and uses **Dependency Injection (DI)** to decouple components and manage service lifetimes.

---

## Features

- **Create:** Add new student records through a form-based interface.
- **Read:** View a list of all registered students.
- **Update:** Edit existing student details.
- **Delete:** Remove student records.

---

## Tech Stack

- **Language:** C#
- **Framework:** ASP.NET MVC
- **Database:** SQL Server *(update if different)*
- **Architecture:** Model-View-Controller (MVC)
- **Design Pattern:** Dependency Injection (DI) for service registration and management
- **IDE:** Microsoft Visual Studio
